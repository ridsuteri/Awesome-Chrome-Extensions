# Dopamodoro - ADHD Pomodoro Timer Chrome Extension

Dopamodoro is a developer-friendly focus tool that combats burnout and screen fatigue by actively gamifying coding and documentation sprints.

## Key Features
- **ADHD-Friendly Gamification**: Designed for executive function support and neurodivergent workflows.
- **Privacy-First**: No background tracking, bloatware, or invasive telemetry.
- **Customizable Sprints**: Flexible timer intervals tailored to deep work.
