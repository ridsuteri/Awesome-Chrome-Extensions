## gTabs - AI Tab Organizer

Organize Chrome tabs with AI. Features smart groups that learn your habits, 8 LLM providers (including local Ollama + Chrome AI), editable suggestions, one-click undo, scheduled re-org, pinned groups, and duplicate finder. Open source, no ads.
